# Default sounds

All CC0 (public domain). Converted to mono MP3.

| File | Source |
|---|---|
| task-done, upload-done, error, mute, unmute, deafen, undeafen, stream-stop | Kenney, Interface Sounds: confirmation_001, drop_002, error_004, switch_001, switch_002, switch_006, switch_007, minimize_006 (https://kenney.nl, https://opengameart.org/content/interface-sounds) |
| join | Froey_, "Message Receive" (https://freesound.org/people/Froey_/sounds/760369/) |
| leave | Froey_, "Message Sent" (https://freesound.org/people/Froey_/sounds/760370/) |
| crow-caw (the @mention sound) | Supplied by the MakeWork project owner |
| mention (the notification sound: replies, private messages, friend requests) | deadrobotmusic, "Notification Sound 3" (https://freesound.org/people/deadrobotmusic/sounds/750609/) |
| stream-start | dland, "hint.wav" (https://freesound.org/people/dland/sounds/320181/) |

join and leave are also used when someone else joins or leaves your call; leave also when your call drops. The Freesound files are the
site's high quality previews.
